| Version | Supported |
| :--- | :--- |

## Reporting a Vulnerability
If you discover a security vulnerability or metadata leakage edge case, please contact developer **Yeasin Arafat Sadiq** directly:
- Website: https://www.sadiqtbh.info

Please include:
- Sample input file format and reproduction steps.
- Output file demonstrating residual sensitive tags.
