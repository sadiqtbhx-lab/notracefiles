# Contributing to NoTraceFiles

Thank you for your interest in improving NoTraceFiles!

## Guidelines
1. **Zero Telemetry Strictness**: No contribution may add analytics, background network tracking, or cloud phone-home features.
2. **Lossless Quality**: Image transformations must preserve the uncompressed raw pixel buffer (0.00% pixel drift).
3. **Open & Free**: No feature paywalls or subscription gates.

## Pull Request Process
1. Fork the repo and create your feature branch: `git checkout -b feature/my-enhancement`.
2. Commit your changes: `git commit -am 'Add new photo format support'`.
3. Push to the branch: `git push origin feature/my-enhancement`.
4. Open a Pull Request detailing the changes and verification steps.
